# HDR 图像处理流水线

这是一个基于 CUDA 的高动态范围 (HDR) 图像处理流水线，用于将 HDR 图像转换为适合显示的低动态范围 (LDR) 图像。流水线包含先进的光晕效果 (Bloom Effect) 处理，模拟真实世界相机的光学特性。

## 代码架构

项目采用模块化设计，主要组件如下图所示：

```
+------------------------+
|       main.cpp         |  <-- 程序入口点
+------------+-----------+
             |
             v
+------------+-----------+    +------------------+
|    HDRPipeline 类      | <--+  envmap 模块     |
| (hdr_pipeline.h/cpp)   |    | (envmap.h/cpp)   |
+------------+-----------+    +------------------+
             |
             v
+------------+-----------+
|  CUDA 核心实现         |
| (hdr_pipeline.cu)      |
+------------------------+
             ^
             |
+------------+-------------------------------+
|                  工具库                    |
+---------+------------+-----------+---------+
| 参数解析 |  图像处理  |  I/O 操作  | CUDA工具 |
|(argparse)| (image.h) | (io.h/png)|  (cuda/) |
+---------+------------+-----------+---------+
```

### 核心组件描述

1. **主入口 (main.cpp)**
   - 处理命令行参数
   - 控制整体执行流程
   - 协调 HDR 流水线处理

2. **HDR 流水线 (hdr_pipeline.h/cpp)**
   - 定义 `HDRPipeline` 类及其接口
   - 实现 HDR 到 LDR 的转换流程
   - 管理 GPU 内存和数据传输

3. **CUDA 实现 (hdr_pipeline.cu)**
   - 包含 CUDA 核函数
   - 实现并行化的图像处理算法
   - 执行色调映射和亮度通道处理
   - **光晕效果处理**：亮通道提取、可分离高斯模糊、能量守恒合成

4. **环境贴图处理 (envmap.h/cpp)**
   - 负责加载和处理 HDR 环境贴图
   - 支持 .hdr 和 .pfm 文件格式

5. **工具库**
   - **参数解析 (argparse.h/cpp)**: 处理命令行参数
   - **图像处理 (image.h)**: 定义图像数据结构和基本操作
   - **I/O 操作 (io.h, png.h)**: 处理文件输入输出
   - **CUDA 工具 (cuda/)**:
     - 内存管理
     - 错误处理
     - 设备信息
     - 事件处理
     - 数组操作

```
| LDR 输出文件 | <-- | CPU 内存(图像) | <-- | GPU 内存(图像) |
+-------------+     +----------------+     +----------------+
```

- CUDA 工具包

1. 创建构建目录：

   ```bash
   cmake ..
   ```

   ```bash
   cmake --build .
   ```

## 使用方法

程序使用方法:
```
hdr_pipeline [{options}] {<input-file>}
options:
  --device <i>          使用CUDA设备<i>，默认值: 0
  --exposure <v>        设置曝光值为<v>，默认值: 0.0
  --brightpass <v>      设置亮度通道阈值为<v>，默认值: 0.9
  --test-runs <N>       平均计时使用<N>次测试运行，默认值: 1
```

### 示例

```bash
./hdr_pipeline --device 0 --exposure 1.5 --brightpass 0.85 input.hdr
```

这将处理 `input.hdr` 文件，使用 CUDA 设备 0，曝光值为 1.5，亮度通道阈值为 0.85，输出为 `input.png`。

## 处理流程

1. **加载 HDR 环境贴图** (.hdr, .exr, .tiff 格式)
2. **将图像数据从 CPU 传输到 GPU**
3. **在 GPU 上执行 HDR 到 LDR 的转换**:
   - **对数亮度计算和自适应曝光调整**
   - **光晕效果处理流程**:
     - 提取亮通道 (`extract_bright_pass`)
     - 水平方向高斯模糊 (`blur_horizontal`) 
     - 垂直方向高斯模糊 (`blur_vertical`)
     - 光晕合成 (`composite_bloom`)
   - **色调映射** (Reinhard算子)
   - **sRGB伽马校正**
4. **将处理后的图像从 GPU 传回 CPU**
5. **保存为 PNG 格式**

## 🌟 光晕效果 (Bloom Effect) 功能

### 功能特性

- **🔍 智能亮通道提取**: 使用色调映射函数和贡献因子精确识别超亮区域
- **⚡ 可分离高斯模糊**: 使用63点高斯核，通过分离卷积优化性能
- **⚖️ 能量守恒合成**: 确保光晕效果不破坏图像整体亮度平衡  
- **🎯 参数可控**: 通过曝光值和阈值精确控制光晕强度
- **🚀 GPU加速**: 全部计算在GPU上并行执行，性能卓越

### 算法实现

光晕效果基于以下数学模型：

```
色调映射函数: τ(v) = v·(0.9036·v + 0.018) / (v·(0.8748·v + 0.354) + 0.14)
贡献因子: β(v) = saturate((τ(v) - 0.8·Ξ) / (0.2·Ξ))²
亮通道提取: B(x,y) = β(eI(x,y)) · I(x,y)
光晕合成: O(x,y) = (1 - β(eI(x,y)))I(x,y) + B̄(x,y)
```

### 处理流程

1. **亮通道提取** - 识别并提取超亮像素
2. **水平模糊** - 使用63点高斯核进行水平方向模糊
3. **垂直模糊** - 继续垂直方向模糊形成完整光晕
4. **能量守恒合成** - 将光晕与原始图像合成

### 使用示例

```bash
# 标准光晕效果
./hdr_pipeline --exposure 1.5 --brightpass 0.8 sunset.hdr

# 强烈光晕效果  
./hdr_pipeline --exposure 2.0 --brightpass 0.6 bright_scene.hdr

# 轻微光晕效果
./hdr_pipeline --exposure 1.0 --brightpass 0.9 interior.hdr
```

### 参数说明

- `--exposure`: 曝光值，控制整体亮度 (推荐: 0.5-3.0)
- `--brightpass`: 光晕阈值，控制光晕强度 (推荐: 0.6-1.0)
  - 值越小 → 光晕范围越大，效果越强烈
  - 值越大 → 光晕范围越小，效果越细腻

### 性能特性

- **内存效率**: 使用可分离滤波器，减少63倍内存访问
- **并行优化**: 所有核函数完全并行化，充分利用GPU算力
- **常量内存**: 滤波器核存储在常量内存中，提供缓存优化
